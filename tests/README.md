# 저장 시스템 브라우저 검증

게임은 `index.html` 하나로 실행되며 별도 빌드가 필요하지 않습니다.
이 테스트는 Node.js 18 이상, Playwright, Chromium을 사용하는 개발용 검증입니다.

현재 클라우드 환경에서는 다음 명령으로 실행합니다.

```sh
node --test tests/save-system.test.cjs
```

Playwright가 없는 환경에서는 저장소 밖에 설치할 수 있습니다.

```sh
npm install --prefix /tmp/mangiworld-test-tools --no-package-lock playwright@1.62.1
NODE_PATH=/tmp/mangiworld-test-tools/node_modules CHROMIUM_PATH=/usr/bin/chromium node --test tests/save-system.test.cjs
```

Chromium 위치가 다르면 `CHROMIUM_PATH`를 지정하세요. 테스트는 임시 HTTP 서버와 각 테스트별 새 브라우저 컨텍스트를 사용하며 사용자의 실제 저장 데이터는 건드리지 않습니다.

검증 범위: 정상/구버전 저장, 잘못된 데이터의 원자적 거절, 수동·자동 저장 분리, 백업 회전/복구, 저장 공간 접근·용량 오류, 파일 입력/다운로드 왕복, 새 게임과 마을 이동, 새로고침 시 자동 저장.

## 저장 규칙 (v3.4.2)

- 기존 `mangiworld_save_1`~`3` 키는 **수동 저장**으로 유지됩니다.
- `_auto`는 자동 저장, `_backup`은 직전 정상 수동 저장, `_autoBackup`은 직전 정상 자동 저장입니다.
- 30초 주기, 구매/제작, 메뉴 복귀, 페이지 종료 저장은 자동 저장에만 기록합니다.
- 수동 저장과 파일 가져오기는 수동 저장에 기록하고 기존 정상 데이터를 백업합니다.
- 손상된 원본을 교체하더라도 정상 백업은 손상된 데이터로 덮어쓰지 않습니다.
- 백업 복구는 선택한 백업을 유지하고 대상 저장만 교체합니다. 현재 플레이에는 불러오기 전까지 적용하지 않습니다.
- 정상 백업 기록에 실패하면 원본 쓰기를 시작하지 않습니다. 원본 `setItem` 실패 시 기존 원본은 유지됩니다.
- 플레이 중인 슬롯은 자동 저장으로 재생성되는 일을 막기 위해 메뉴에서 바로 삭제할 수 없습니다. 메인 메뉴로 돌아가 삭제하세요.
- 저장 형식은 버전 3입니다. 버전 없음/1/2의 기존 저장을 임시 객체에서 변환합니다. 이전 게임 버전에서 새 저장을 불러오는 역방향 호환성은 보장하지 않습니다.
- 백업 역시 같은 브라우저의 localStorage에 있으므로 사이트 데이터 삭제·기기 변경에 대비하려면 파일로 내보내야 합니다.
