# 게임 브라우저 회귀 검증

게임은 `index.html` 하나로 실행되며 별도 빌드가 필요하지 않습니다.
이 테스트는 Node.js 20 이상, 개발용 Playwright, Chromium을 사용합니다.

```sh
npm ci
npm test
```

시스템 Chromium이 없다면 `npx playwright install chromium`을 실행합니다. 다른 경로의 Chromium은 `CHROMIUM_PATH`로 지정합니다. `/usr/bin/chromium`이 있으면 이를 우선 사용하고, 없으면 Playwright가 설치한 브라우저를 사용합니다. 홈 디렉터리 쓰기가 제한된 환경에서는 `npm ci --cache /tmp/mangiworld-npm-cache`를 사용합니다.

- `npm run test:save`: 정상·구버전 저장, 잘못된 데이터 거절, 수동·자동 저장 분리, 백업, 접근·용량 오류, 파일 입력·다운로드, 종료 저장.
- `npm run test:session`: 새 게임 초기화, 불러오기 시 일시 상태 정리, 메인 메뉴 복귀/취소/저장 실패, 루프 중복과 이전 타이머 제거, 실제 이동·일시정지·무기 전환·세 무기 평타, 대표 던전의 처치·정예·생존 목표와 포탈 이동, 세 스승의 일반 스킬 습득·각성 시련·재대결·저장 유지, 엔딩 전환, 설정 유지.

- `npm run test:input`: 포커스/탭 전환 후 수동 재개, 반복 키 입력 차단, 대화·상점·알림·탑 선택의 입력/시간 차단, 저장·설정·중첩 창의 Escape 순서, 전투 타이머 정지, 정상 패널 입력 유지, 입력 필드·브라우저 단축키, 충전 스킬의 정지·재개.

- `npm run test:timing`: 제어된 실제 브라우저 RAF 간격으로 30·60·144Hz 이동/타이머 일치, 히트스톱과 자동 저장, 정지/재개·긴 공백·따라잡기 상한, 평타 시계, 숨겨진 HUD의 쿨타임, 중간 틱의 모달 진입, 최종 표시 픽셀 일치, 바닥 최적화의 픽셀·호출 횟수·캐시 상한과 겹친 주문 전투를 검증합니다.

- `npm run test:layout`: 9개 대표 화면의 비율·화면 범위·메뉴 접근, 접이식 패널의 정지·조작·포커스·Escape, 크기 변경 전후 조준과 클릭, 툴팁 경계, 짧은 화면의 상점/저장 스크롤, 불러오기 후 진행 표시, ICO 응답과 글꼴 실패 시 실행을 검증합니다.

- `npm run test:objectives`: 초반 자동 안내, 의뢰 수락/처치/보상/반복, 실제 해금 조건, 세 종류의 던전 목표와 보스, 현재 맵 방향, 추적 저장/버전 3 변환/잘못된 메타데이터, 메뉴 정지/포커스/작은 화면, 각성 재료/개별 과제/재대결, 실제 탑 30층 완료와 불러오기 상태 일치를 검증합니다.

- `npm run test:equipment`: 무기별 비교 기준·미리보기 순수성·실제 장착과 알려진 수치 일치, HP 반올림/버프/상한, 빈 슬롯/동일 장비, 잠금 이동/저장/제작·판매 보호, 가방 포화, 스택 사용/등록/교체 수량 보존, 상점 미리보기, 브라우저 단축키/키보드 검사/작은 화면 툴팁/패널 동작, 이전 저장 변환과 버프 만료 시 비교 갱신을 검증합니다.

- `npm run test:combat`: 실제 접촉·투사체·범위·주기 피해의 출처/수치, 사망 프레임과 잔여 효과 정리, 던전 및 세 스승 일반/각성 재도전, 해금·대기시간·탑·중복 보상 차단, 불러오기 초기화, 피격 기록의 정지·포커스·작은 화면, 도입부/엔딩 시청 여부 및 건너뛰기 보상·완료의 단일 실행을 검증합니다. RAF는 수동 시계로 제어하며 모든 보스 패턴을 전수 검사하지는 않습니다.

- `npm run test:accessibility`: 시작/일시정지 설정의 Tab·Escape·초점 복귀, 전 설정의 재실행/세션 교체 유지, 키 변경 후 실제 이동·달리기·스킬·충전·물약·가방 등록·훈련 조작, 키 중복/예약 키/브라우저 단축키 보호, Web Audio의 실제 gain 배율, 히트스톱과 Canvas 섬광 강도, 큰 글자의 3개 화면 크기, 기본값 복원·손상 설정·저장 실패, 수동/자동 저장·잠금·목표·보스 재도전 연동을 검증합니다. 음량 검사는 Web Audio 노드에 전달하는 값을 검증하며 기기 스피커의 출력까지 측정하지 않습니다.

- `npm run test:admin`: 코드 오류/비활성 기능 차단, 시작/플레이 진입과 종료/새로고침 복구, 일반 수동/자동/백업/가져오기/삭제/불러오기/종료 저장 보호, 수치 검증과 아이템 수량, 실제 피해/마나/쿨타임/AI·투사체·위험지대 정지, 각 전투·프리셋·진행도·전용 저장, 피해 측정, 메뉴 입력/초점/작은 화면/미리보기, 복구 저장/삭제 실패와 손상 데이터, 엔딩 중 도구 재진입을 검증합니다. 관리자 코드는 클라이언트 테스트 도구이며 서버 인증을 검증하는 테스트가 아닙니다.

`tests/helpers/browser.cjs`가 임시 HTTP 서버와 브라우저 생명주기를 관리합니다. 각 테스트는 새 브라우저 컨텍스트를 사용하고 사용자의 실제 localStorage를 읽거나 변경하지 않습니다. 예상하지 않은 페이지 오류도 테스트 실패입니다.

긴 플레이를 반복하는 대신 일부 테스트는 마지막 처치 직전의 진행도, 각성 재료·과제 등의 전제를 준비합니다. 이후 실제 게임의 피해/승리 처리, 프레임 갱신, UI 클릭과 저장·불러오기 경로를 검증합니다. 전체 게임 플레이나 모든 보스 패턴·밸런스를 검증한 것은 아닙니다. 선택 사항인 외부 글꼴은 테스트에서 차단하여 네트워크에 의존하지 않습니다.

GitHub Actions 설정은 `.github/workflows/test.yml`에 있습니다. 로컬 테스트 통과와 원격 CI 실행 결과는 별개입니다.

## 저장 규칙

- 기존 `mangiworld_save_1`~`3` 키는 **수동 저장**으로 유지됩니다.
- `_auto`는 자동 저장, `_backup`은 직전 정상 수동 저장, `_autoBackup`은 직전 정상 자동 저장입니다.
- 30초 주기, 구매/제작, 메뉴 복귀, 페이지 종료 저장은 자동 저장에만 기록합니다.
- 수동 저장과 파일 가져오기는 수동 저장에 기록하고 기존 정상 데이터를 백업합니다.
- 손상된 원본을 교체하더라도 정상 백업은 손상된 데이터로 덮어쓰지 않습니다.
- 백업 복구는 선택한 백업을 유지하고 대상 저장만 교체합니다. 현재 플레이에는 불러오기 전까지 적용하지 않습니다.
- 정상 백업 기록에 실패하면 원본 쓰기를 시작하지 않습니다. 원본 `setItem` 실패 시 기존 원본은 유지됩니다.
- 플레이 중인 슬롯은 자동 저장으로 재생성되는 일을 막기 위해 메뉴에서 바로 삭제할 수 없습니다. 메인 메뉴로 돌아가 삭제하세요.
- 저장 형식은 버전 5입니다. 버전 없음/1/2/3/4의 기존 저장을 임시 객체에서 변환합니다. 이전 게임 버전에서 새 저장을 불러오는 역방향 호환성은 보장하지 않습니다.
- 백업 역시 같은 브라우저의 localStorage에 있으므로 사이트 데이터 삭제·기기 변경에 대비하려면 파일로 내보내야 합니다.

입력 테스트는 실제 Chromium 탭 전환과, 결정적으로 재현하기 위한 blur/visibilitychange 이벤트를 모두 사용합니다. 실제 탭 전환 테스트에서는 Playwright가 기본으로 켜는 포커스 에뮬레이션을 CDP로 해제한 뒤, 이동 중 다른 탭으로 전환하고 돌아와도 재개되지 않는지 확인합니다.

시간 테스트의 `tests/helpers/manual-clock.cjs`는 RAF 전달 시각만 제어합니다. 실제 HTML의 게임 로직과 Canvas는 그대로 실행하며, 모든 시나리오는 별도 컨텍스트를 사용합니다. 생존 목표는 마지막 2초 직전 상태에서 검증하며 90초 전체 플레이를 반복하지 않습니다.

반복 바닥 테스트는 기존 타일 그리기와 실내/실외·비정수/음수 시작 좌표의 실제 픽셀을 비교합니다. 성능 측정은 호출 수 감소를 단언하고 실행 시간은 참고용으로만 출력합니다. 12마리 몬스터와 겹친 지팡이 주문의 측정 역시 JS 실행 및 Canvas 명령 제출 시간이며, GPU 전체 프레임 시간이나 모든 기기의 FPS를 보장하는 수치가 아닙니다.

화면 테스트는 실제 CSS 레이아웃과 브라우저 입력을 사용합니다. 조준은 CSS 픽셀 하나 이내의 브라우저 포인터 정수화 오차를 허용합니다. 이는 잘못된 크기 변경 좌표 변환을 허용하는 범위가 아닙니다. 터치 게임패드나 모든 기기·브라우저를 검증한 것은 아닙니다.

목표 테스트는 지도 간 다음 출구와 실제 엔진의 처치·보상·탑 클리어 처리를 검증합니다. 모든 지도에서 자동 길찾기를 수행하는 테스트는 아니며 방향 표시는 장애물 회피를 대신하지 않습니다. 목표창 선택은 수락·보상을 실행하지 않는지도 별도로 확인합니다.

`npm run test:graphics`: 도입부 목표·키보드 진행·중복 보상 방지, NPC 초상화와 역할별 외형, 다섯 지역/몬스터 렌더링의 게임 상태 보존, 작은 화면과 스승의 공통 외형을 검증합니다.
